# @sgrs/api-schema

Zod schemas and OpenAPI 3.1 spec for the SGRS REST API. Source of truth for
both `@sgrs/client` (TypeScript) and `sgrs-client` (Python).

Static HTML for the OpenAPI document (Redoc) plus TypeDoc for the TS client is produced by **`pnpm docs`** in the repo root (package `@sgrs/docs`).
